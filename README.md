# WiseWeek

WiseWeek is an AI-powered weekly planner designed to help users plan realistically, stay balanced, and avoid burnout. Instead of being just another to-do list, WiseWeek focuses on helping users make better planning decisions through intelligent insights, realistic scheduling, and productivity analytics.

## Features

* Weekly planning dashboard
* Today's Focus
* Energy-based task planning
* Reality Check (planned workload vs available time)
* Life Balance Meter
* Priority Pyramid (3 Must-Do tasks)
* Smart Carry Forward for unfinished tasks
* Mood & productivity tracking
* AI-powered weekly reflections
* Time Leak Detector
* Weekly Memory Timeline
* Reverse Planning
* Tiny Wins progress tracking
* Responsive light & dark mode UI

## Current Status

This repository currently contains the interactive prototype of WiseWeek. The project is being developed incrementally and will evolve into a full-stack web application.

## Vision

Most productivity tools help users organize tasks.

WiseWeek aims to help users **plan smarter**, maintain a healthy work-life balance, and build sustainable productivity habits through thoughtful design and AI-assisted planning.
